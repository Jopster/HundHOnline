# HHOdoo

Odoo-18-Addon fuer H&H-Projektverwaltung.

## Funktionen

- Erweiterte Projektstammdaten: H&H-Referenz, Ansprechpartner, Status und Zieltermin
- Projekttermine mit Verantwortlichen und Beschreibungen
- Globale Einstellungen fuer Dokumentenpfad und Wartungsmodus

## Installation

1. Den Ordner `HHOdoo` in einen konfigurierten Odoo-Addons-Pfad kopieren.
2. Die App-Liste aktualisieren.
3. **HHOdoo** installieren.

Das Modul setzt die Odoo-Apps **Projekte** und **Kontakte** voraus. Die technische Modulkennung ist `HHOdoo`.
